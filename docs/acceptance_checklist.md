# PLT 工具与车联网协议总体验收清单

2026-11-17 Workspace 迁移说明：本文源码链接与复测命令已适配独立 `plt` package；历史 JSON、数值与源码指纹保持原样，见[迁移记录](workspace_migration.md)。

更新日期：2026-11-13。适用目标：将 PLT 用作车联网跨域认证、门限授权或密钥协商协议的底层工具。

## 1. 验收目标和投入边界

目标是**正确实现所使用的 PLT 构造，并验证上层协议所依赖的条件**。
不要求重新完成一篇底层密码学论文，但实现、参数和协议假设仍然要相互对应。
工程安全需要有明确攻击模型和验证证据；研究方向不改变底层原语失效对协议的影响。

可以不做的工作：

| 内容 | 本项目的处理方式 |
| --- | --- |
| 重新证明 PLT 的 One-wayness、Indistinguishability | 引用已有结论，列明适用条件及实现差异；差异未解决时，不将结论直接套用到当前代码。 |
| 重现 D0–D4 混合证明、重新证明 Lemma 14 | 阅读并核对实际依赖的前提，不重新撰写证明。 |
| 用有限实验测出“可忽略统计距离” | 不作为验收要求；实验只能排查明显异常，分布保证来自算法及条件分析。 |
| NIST 标准化级别认证、完整生产密码模块审计 | 不作为协议研究原型的门槛；真实部署需另行制定要求。 |
| 全部环格版本和任意门限规模 | 只实现论文实验或协议声称支持的范围，不为完整性额外扩展。 |

建议引用 [PLT 作者公开版](https://olapiha.github.io/assets/pdf/TTrap.pdf)：第 3.5 节的底层接口条件、
第 5.2 节图 2 的算法、第 5.3 节 Lemma 14，以及 Table 2 的参数条件。
文献引用用于说明构造依据，不代替实现核查。

## 2. 三个阶段的通过条件

| 阶段 | 通过后可以做什么 | 当前状态 |
| --- | --- | --- |
| G0：流程原型 | 演示可配置 t-of-k、进行小参数算法开销实验、开发上层接口。 | 统一接口已覆盖 2-of-3、3-of-5 和 5-of-10 正确性；计时记录的版本范围见 D1。 |
| G1：受控协议实验 | 在明确参数及原语假设下研究协议安全，运行协议仿真和攻击测试。 | 未完成；B1/B2 工程检查和 B4 有限筛查已完成，B3 当前参数明确不通过，C 类协议尚未实现。可继续框架与仿真，但不能把当前 PLT 当作独立不可伪造原语。 |
| G2：实际部署 | 处理真实凭证和长期密钥，在对抗环境中运行。 | 不在当前验收目标内；另行审查密钥管理、侧信道、依赖、运维和故障恢复。 |

G1 不要求重证 PLT 定理。它要求说明“采用什么原语、在什么条件下使用、协议如何依赖它”，
并补上实现和实验能验证的部分。若只使用小参数模拟 PLT，实验结论应限于流程和性能原型；
协议层可以作条件性安全分析，但不能宣称这份小参数实例已经实现了相应安全保证。

### C. 上层认证、门限授权和密钥协商

- [ ] **C1｜不足门限不能绕过协议授权。状态：待做，上层协议尚未实现。**
  - 验收：写明信任方、腐化门限、静态/自适应腐化范围、攻击者可请求的会话及泄露信息；
    说明 PLT 原有性质如何进入协议论证。按声称范围测试零份、一份、串谋、跨会话份额拼接和未授权目标请求。
  - 关键：代理在采样前也要验证请求权限。拒绝不足两份输入的 API 只能说明输入规则，不能证明攻击者算不出另一份或完整原像。
    消息带有效签名也不自动证明对特定目标具有门限授权，需说明代理的授权策略。

- [ ] **C2｜非法份额、重复份额和节点失效得到处理。状态：部分。**

  - 缺口：网络份额验证和恶意份额测试。`rec` 不是可验证份额协议；拒绝错误结果不等于定位恶意节点或保证继续完成。

- [ ] **C3｜身份、消息和会话绑定，具备重放防护。状态：待做。**

  - 新鲜性方案有设计依据：若用 nonce，规定生成和去重；若用时间戳，规定时钟误差和接收窗口；

- [ ] **C4｜会话密钥或凭证输出满足协议声称的性质。状态：待做；按协议范围适用。**

    分别说明会话密钥秘密性和协议声称的前向安全、KCI 等性质。不能从 PLT 门限功能直接推出这些性质。
  - 若只有门限认证/凭证转换：以凭证有效性、接收者及权限绑定替代密钥协商项目，并记录不适用原因。
  - 秘密原像不是自动可用的会话密钥，公开或可观察输出不能直接作为秘密密钥材料。

| gadget | 底数 2，长度 ceil(log2(q)) | 对应配置模数的长度 | 对应底层构造及参数条件 |

特别注意：当前是公开的低维线性方程实例。仅求出满足 `Ax=y mod q` 的整数向量不需要陷门，
其难点本应是所需的短度或其他安全条件；当前小参数和宽松范数界没有建立该困难性。
这不会妨碍进行协议流程原型实验，但必须在不足门限安全分析中说明采用的实际安全依据。

## 5. 重复采样的实用检查计划

以下保留通用复测原则；首轮已经按[预先登记计划](plt_B_experiment_plan.md)实施，见[B 类结果](plt_sampling_B.md)。
参数或实现变更后应重新登记范围，先小规模排错，再决定是否扩大；默认起点为每组 3 套独立陷门、每套三种目标各 1,000 次。
长期代理若声称支持大量请求，再增加长序列和并发压力场景。样本数是工程起点，不是安全参数。

1. **逐样本检查**：四条恒等式、整数表示、有限数、分解残差和范数；记录失败而非丢弃异常样本。
2. **随机性检查**：固定陷门与目标重复调用，记录完全重复率和序列相关性；用适合实际离散分布的参照解释重复率，
   不把“出现相同样本”直接判错，也不把“全部不同”视为 CSPRNG 保证。
3. **形状与尺度检查**：统计均值、投影、平方范数与相关结构，比较预期分布或可核实的小维度参照采样。
   对小维参照截断枚举时记录截断范围及尾部误差；不要直接用连续高斯替代离散条件分布作为精确标准。
4. **区分条件**：固定非零目标时，样本位于特定陪集，均值不一定为零；零目标时可检查符号对称性。
   x_j 位于低秩子格，其环境空间协方差不应被机械要求为 sigma² I。
   `Sigma/(2*pi)` 是连续高斯换算关系，离散条件样本的经验协方差也不必严格等于它。
5. **检查判据**：在运行前登记样本量、参照、精度/尾部/相关性指标和容许误差，说明抽样误差与多重比较的处理。
   不采用一个无依据的统一 p 值作为安全通过线；明显异常必须解释、修复或缩小结论范围。
6. **记录结论**：输出数据摘要、图表、异常说明和“仅排除所测异常”的结论，引用 B1–B3 作为额外依据。
