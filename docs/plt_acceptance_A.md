## 4. A4：范数与失败语义

### 接收方入口

- `verify_preimage(public, target, x, sigma_squared)`：检查目标、整数向量尺寸、正且可处理的宽度、完整原像范数和 Ax=y。
- `verify_partial_preimage(public, id, set, target, x_j, sigma_squared)`：检查集合、目标分量、公共像和部分原像范数。
- `rec` 调用同一检查后求和，再验证完整结果，不能只依赖原像的内部类型或生成方的声明。

目标与宽度来自验证方批准的协议上下文，不能让对方通过随意扩大 sigma 放宽短度限制。
部分原像验证不证明其属于秘密 U 子格，也不替代身份、会话和授权认证；这些仍是 C 类工作。

### 范数和数值错误

设 D=2mt，逐次检查发行列范数不超过 D(r*s)²、部分原像范数不超过 D*sigma²、完整原像范数不超过 t²D*sigma²。
返回 `NormExceeded` 后不自动重采样，也不放宽 sigma/beta。任意高斯采样存在尾部失败可能；
发布给外部的成功输出是以通过检查为条件的分布，这个拒绝机制的分布/协议影响仍需 B 类分析。

Setup 现在返回 `Result`。PLT 路径复用 MP12 的 fallible 核心：
`try_trap_gen`、`try_compute_sqrt_sigma_2`、`try_samp_p`。
旧 PSF 接口为了兼容保留 expect/panic 语义；PLT 不通过这些旧接口隐藏失败。

错误类型区分非法输入/上下文、秩不足、宽度不足、范数越界、非正定、数值错误、代数错误和后端失败。
浮点计算检查有限数、正分解主元和最大元素尺度下的相对重构残差（1e-8）；该数值守卫不等同于完整误差或统计距离证明。
不使用 catch_unwind 吞掉任意错误。内存耗尽、系统终止、FFI abort 不在可恢复错误保证内。

### 负面测试

- 保持 Ax 不变地给 x 加巨大 q 的倍数：完整验证、部分验证和 Rec 都拒绝超长结果。
- 错误列数、错误模数、零宽度、超出 f64 范围的宽度被拒绝。
- 非正定、非对称、错误尺寸及非有限扰动参数返回错误。
- 后端参数错误向上返回；故意设置不可能的发行范数界会中止发行，不触发隐式重试。
- 元数据仍然匹配、但份额值/形状被故障注入修改时，Rec 依然检查并拒绝。

## 5. 重复操作结果

每组配置使用 3 套独立生成的密钥，每套执行 1,000 次恢复。恢复集合循环覆盖全部合法集合；
目标在零向量、模数边界向量和随机目标之间轮换。失败操作会被记录，跳过的计划试验单独计数，
不会通过只统计成功样本隐去失败。该实验没有声称模拟完整部署寿命。

| 配置 | Setup 尝试 | PTrapGen 尝试 | PSampPre 尝试 | 恢复成功/尝试 | 范数失败 | 跳过恢复 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 2-of-3 | 3 | 9 | 6,000 | 3,000/3,000 | 0 | 0 |
| 3-of-5 | 3 | 15 | 9,000 | 3,000/3,000 | 0 | 0 |
| 5-of-10 | 3 | 30 | 15,000 | 3,000/3,000 | 0 | 0 |

本次共 9,000 次恢复、30,000 次部分采样，阶段错误记录为空，观测失败率为 0/9000。
复用密钥和目标类别使试验并非简单独立同分布模型，不从零次失败推出真实失败率为零或安全概率界。
此项完成 A4 的重复运行和失败计数，未完成 B4 对分布形状、重复/相关结构等的检查。

结果快照：[JSON](plt_acceptance_A_results.json)。其中保存该次实际参数、集合尝试数和源文件 SHA-256，
没有保存 R、U、d 或 x 等秘密/样本向量；重跑 target 中的文件不会覆盖此文档快照。
