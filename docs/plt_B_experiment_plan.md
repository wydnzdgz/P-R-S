# B 类实验预先登记计划

日期：2026-11-13。以下阈值在本轮实验运行前确定，目的为排查明显异常；不作为分布距离或安全证明。

## B2 数值检查

- 默认 2-of-3、3-of-5、5-of-10，每组 3 套独立密钥；每套检查所有参与者的实际 Gram/Sigma/扰动矩阵。
- 精确检查 `Gram*Sigma=sigma² I`；独立重构目标平方宽度，最大元素相对残差 <=1e-8。
- 记录矩阵无穷范数条件数；运行时拒绝 `kappa_inf*epsilon_f64>1e-8`、非有限数、非正主元。
- 合成矩阵补测良态、近奇异、尺度失衡、非对称、非正定及超出浮点范围的情况。
- 不将通过有限精度检查等同于统计距离保证。

## B3 参数反例

- 仅用 A 和 y 进行模素数高斯消元，令自由变量为零，取中心剩余类作为整数原像。
- 对满行秩 A，得到的解至多 nt 个非零坐标，范数平方不超过 `nt*floor(q/2)^2`。
- 使用已批准的实验 sigma² 调用原像验证接口，检查公开解是否被接受；禁止在解算函数中使用陷门或份额。
- 如果被接受，B3 判定为“不通过”，不把增加 n 或测试通过视为修复，不自动给出未经评估的安全参数。

## B4 PLT 重复采样

- 每组 3 套密钥；每套按固定规则选择一个参与者（首、中、末编号）和含该参与者的合法恢复集。
- 每套分别使用零目标、确定性非零目标、一次生成后固定的随机目标，各采样 1,000 次。
- 合计 27 组、27,000 次部分采样；所有失败计入，不剔除、不重采样。
- 用 `w=sqrt(2*pi)/sigma * chol(U^T U)^T d` 检查尺度。连续近似仅用于粗略筛查；离散条件分布不被假定精确等于连续高斯。
- 各坐标方差允许 [0.7,1.3]；最大绝对坐标相关 <=0.2；每坐标 lag-1 相关绝对值 <=0.2。
- 仅零目标要求最大绝对坐标均值 <=0.15；非零目标均值照常记录，不强制零均值。
- 报告重复完整样本数量及范数失败；固定大维实验中若完全重复则作为需调查异常，不宣称任意离散采样都不应重复。

## B4 小维独立离散参照

- 独立检查底层 SampPre：q=3、n=1、3 个原像坐标，r=4。
- 平方宽度矩阵固定为 `[[3200,800,0],[800,4800,400],[0,400,6400]]`，分别测试目标 0、1。
- 每个目标采样 10,000 次；枚举 [-220,220]^3 中满足 C*d=z mod 3 的所有整数点，权重为 `exp(-pi*d^T*Sigma^-1*d)`。
- 对 d1、d2、d3、d1+d2 四个投影计算离散 CDF 与经验 CDF 的最大绝对差，每项 <=0.04。
- 使用最大行和 V=6800 给出遗漏质量上界，再除以枚举的分区函数下界；要求截断相对质量界 <1e-8。
- 正权重浮点累加和 exp 仍有数值误差；记录枚举点数与截断界，不把枚举结果称作符号精确证明。
- 统计投影落在参照区间外的数量；本轮要求为零。任何检查失败都保留结果并调查，不能运行后调整阈值抹掉异常。

本轮不测隐私泄漏不可区分性，不宣称检验通过即满足 PLT 的全部安全定义。
